# 温家宁生日邀请函

独立、无依赖的静态网页。访客输入姓名后，会收到写有自己名字的拟真信封；从信封纸面的任一边缘按住并移动鼠标或手指，纸张会沿实际移动轨迹向内撕开。裂口呈现参差的纸纹和棉纸纤维，露出下方的黑红邀请卡，随后进入个性化邀请卡。

## 本地预览

在此目录运行任意静态 HTTP 服务，例如：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。网站不需要构建命令、账号、数据库或外部字体 / CDN。

## 操作

- **鼠标与触屏：**从信封纸面的上、下、左、右任一边缘按住，朝纸面内滑动。撕口沿指针轨迹生长，边缘带有纸纹、棉纤维与贴近纸面的阴影，下方可见黑红邀请卡。松手后短撕口保留，可从撕口尖端继续撕。直接在纸面中央按下不会凭空产生裂口。
- **直接打开：**信封下方有“直接打开邀请函”按钮。用键盘聚焦信封后，也可以按 Enter 或空格打开。单击信封纸面不会直接跳过撕纸过程。
- **重看：**邀请卡上可返回信封，或更换收信人姓名。页面尊重系统的“减少动态效果”设置。
- **保存卡片：**邀请卡下方点击“保存专属卡片”，网页会生成带收信人姓名和二维码的高清 PNG，并尝试立即下载。在限制下载的微信内置浏览器中，还会显示图片供长按保存。
- **音乐：**提交姓名时，网页会在这次点击或回车操作中立即播放 Кино《一颗名为太阳的星》。音乐在信封与卡片之间连续播放；返回姓名页时停止并从头重置。如果手机浏览器阻止播放，信封页的音乐按钮会提示“点此播放”。

页面按手机竖屏设计，同时支持桌面鼠标。交互发生在浏览器本地；访客姓名只在当前页面内存中用于显示，不会发往服务器或写入浏览器存储。

## 视觉素材

信封照片底图由内置 ImageGen 制作。最终素材提示词的要点是：摄影棚俯拍微距，一只由厚实米白色棉絮纸制成的平面信封，右下角有深红火漆封印，没有文字和三角折盖。后续修图去掉了三角折盖，同时保留纸张纤维、自然纸边与火漆细节。互动撕口由网页实时生成，会跟随访客的实际手势。

音乐文件为站点拥有者提供的授权录音，存放在 `assets/star-called-sun.mp3`。发布时须保留该文件与网页的相对路径。

## 发布与分享

该网站从 GitHub 仓库 `main` 分支根目录通过 GitHub Pages 发布。分享时将以上 HTTPS 链接发到微信朋友圈，或分享同一网址的二维码。网站不用 ChatGPT Sites。上传时须保留 `card-export.js`，保存卡片功能由它实现。

页面已设置横版分享图 `assets/share-card.png` 的绝对地址及 Open Graph 元信息。实际微信卡片样式仍由微信客户端决定；发布后应从微信中打开链接检查。
